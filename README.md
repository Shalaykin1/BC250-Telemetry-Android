# BC250-Telemetry-Android

Android-приложение для отображения телеметрии материнской платы AsRock BC-250,
повторяющее внешний вид web-дашборда из проекта
[onlinermm/BC250-Telemetry](https://github.com/onlinermm/BC250-Telemetry).

## Как это работает

1. При запуске приложение ищет плату BC-250 в текущей Wi-Fi сети:
   - сначала пробует последний сохранённый IP-адрес (быстрое переподключение);
   - если он недоступен, сканирует подсеть телефона (`/24`) на предмет
     отвечающего сервиса `bc250-web.service` на порту `8090` (проверяется
     валидный ответ `/api/telemetry`).
2. После обнаружения раз в ~700 мс опрашивается `http://<ip>:8090/api/telemetry`
   — тот же JSON, что отдаёт демон `apu_telemetry` на самой плате.
3. Данные отображаются в карточках CPU / GPU / Other Sensors / GDDR6 Memory —
   те же метрики (VIN/VOUT/IOUT/POUT, температуры, частоты, PPT, вентилятор),
   что и в оригинальном web-интерфейсе.
4. Если связь пропадает на несколько циклов подряд, приложение автоматически
   возвращается к поиску устройства.
5. Помимо нативного Android-интерфейса приложение умеет показывать
   собственную веб-панель платы (WebUI V2 из `bc250-web.service`, `/v2/`) в
   WebView. При первом запуске приложение спрашивает, какой режим
   использовать; переключиться между режимами позже можно пятью быстрыми
   нажатиями по экрану — выбор запоминается.

## Сборка

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Подписанный релизный APK собирается командой `./gradlew assembleRelease` и
появляется в `app/build/outputs/apk/release/app-release.apk`.

## Требования на плате

На BC-250 должен быть установлен и запущен `bc250-web.service` из репозитория
[onlinermm/BC250-Telemetry](https://github.com/onlinermm/BC250-Telemetry)
(`sudo ./install.sh`), слушающий порт `8090` в той же Wi-Fi сети, к которой
подключён телефон.
